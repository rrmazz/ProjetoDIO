O que é HTML?

Voltar

HTML é uma linguagem utilizada para criar a estrutura de páginas da internet.

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto.

Com HTML podemos criar títulos, parágrafos, listas, links e vários outros elementos para organizar uma página.

Por que aprender HTML?

Voltar

Aprender HTML é um ótimo primeiro passo para quem deseja entrar no mundo do desenvolvimento web.

Durante os estudos, podemos aprender diferentes elementos e descobrir como cada um deles funciona.

Títulos

Voltar

O HTML possui seis níveis de títulos, que vão do primeiro nível até o sexto nível.

Você pode utilizar esses níveis para organizar o conteúdo de uma página.

Listas

Voltar

Existem diferentes tipos de listas que podem ser utilizadas para organizar informações.

Lista de tecnologias:

  • HTML
  • CSS
  • JavaScript
  • Python

Lista de passos para criar uma página

  1. Criar o arquivo HTML.
  2. Adicionar a estrutura básica.
  3. Inserir os conteúdos.
  4. Salvar o arquivo.
  5. Abrir a página no navegador.

Um pequeno exemplo

Voltar

Podemos utilizar diferentes estilos para destacar determinadas palavras ou informações importantes.

Também podemos criar links para acessar outros sites.

Exemplo de uma fórmula: H2O.

Exemplo de potência: 23 = 8.

Uma informação pode ser considerada importante quando queremos chamar a atenção do leitor.

Uma frase antiga pode ser apresentada como removida ou substituída por outra.

Uma abreviação também pode receber uma explicação para facilitar o entendimento do leitor.

A prática é uma das melhores formas de aprender programação.

Conclusão

Voltar

HTML pode parecer complicado no começo, mas com a prática fica cada vez mais fácil.

O mais importante é entender para que serve cada elemento e experimentar diferentes possibilidades.

Continue praticando e, aos poucos, você será capaz de criar páginas cada vez mais completas.
